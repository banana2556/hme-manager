手動匯入 Session

  1. 前往 iCloud+（大陸帳號請改用 icloud.com.cn），開啟 Hide My Email（隱藏我的電子郵件）。
  2. 按 F12 開啟 DevTools → Network，找到包含 list?clientBuildNumber 的請求。
  3. 對該請求選擇 Copy as cURL (bash)，貼到下方；也可貼上包含 request cookies 的 HAR JSON。區域會依主機自動判定。
  4. 若要在「收件匣」讀信，請先在 iCloud 網頁開啟過一次 郵件 再複製請求，確保 cookie 帶有郵件授權。
